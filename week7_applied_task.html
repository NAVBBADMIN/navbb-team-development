This Week's Task
Pick one location that's been fighting you. Write it down. Try one new thing.

The constraint doesn't go away by complaining about it or hoping the location changes. Document it specifically — what the actual setup problem is, what you've already tried, and one thing you haven't tried yet. Then go try it. Come back and reflect honestly on what happened.

What have you already tried at this location?

Be honest. If the answer is "the same thing every time," write that.

What's one thing you haven't tried yet?

Specific. Not "a different approach" — the actual thing. Call ahead and ask for system access. Show up unannounced with something for the owner. Position yourself at the exit instead of the entrance. Name it.

After the visit — what happened?

Did you try it? What was the result? Did it change anything? Be honest — a result of "tried it, didn't work, now I know" is just as useful as a success.
